वार्षिक सांस्कृतिक कार्यक्रम एवं पुरस्कार वितरण

ICT स्मार्ट लैब एवं इंफ्रास्ट्रक्चर

स्मार्ट एजुकेशन सिस्टम:

  • कंप्यूटर लैब: विद्यार्थियों के लिए आधुनिक डेस्कटॉप सिस्टम और ब्रॉडबैंड कनेक्टिविटी।
  • प्रोजेक्टर क्लासरूम: ऑडियो-विजुअल माध्यम से कठिन संकल्पनाओं को आसान बनाना।
  • डिजिटल साक्षरता: MS Office, Internet, Coding Basics और Cyber Safety की ट्रेनिंग।

ICT पाठ्यक्रम (Curriculum)

कक्षा 9वीं से 12वीं तक सूचना प्रौद्योगिकी (IT Code 402) एवं कंप्यूटर साइंस (Python, SQL) की नियमित प्रैक्टिकल कक्षाएं।

हार्डवेयर नोट्स (Hardware Notes)

मुख्य हार्डवेयर कंपोनेंट्स:

  • इनपुट डिवाइस: Keyboard, Mouse, Scanner, Barcode Reader, Webcam.
  • प्रोसेसिंग डिवाइस: Central Processing Unit (ALU, CU, Registers).
  • स्टोरेज डिवाइस: HDD, SSD, RAM, ROM, Pen Drive.
  • आउटपुट डिवाइस: Monitor, Printer, Projector, Speaker.

सॉफ्टवेयर नोट्स (Software Notes)

सॉफ्टवेयर के प्रकार:

  • System Software: Operating Systems (Windows, Linux, Android) और Drivers.
  • Application Software: MS Office Suite (Word, Excel, PPT), Google Chrome, Tally.
  • Utility Software: Antivirus, Disk Cleaners, Backup Tools.

इंटरनेट नोट्स (Internet Notes)

नेटवर्किंग और इंटरनेट सिद्धांत:

  • Internet: विश्व भर के नेटवर्कों का जाल जो TCP/IP प्रोटोकॉल से संचालित होता है।
  • WWW: World Wide Web, इंटरनेट पर स्टोर किए गए इंटरलिंक्ड वेब पेजों का संग्रह।
  • IP & DNS: इंटरनेट प्रोटोकॉल एड्रेस और डोमेन नेम सिस्टम की कार्यप्रणाली।

ईमेल नोट्स (Email Notes)

इलेक्ट्रॉनिक मेल:

  • प्रोटोकॉल: SMTP (भेजने के लिए), POP3 और IMAP (प्राप्त करने और सिंक करने के लिए)।
  • फील्ड्स: To, Cc (Carbon Copy), Bcc (Blind Carbon Copy), Subject Line.

Class 9th: Science (विज्ञान)

मुख्य अध्याय व बिंदु:

  • Matter in Our Surroundings: ठोस, द्रव और गैस; वाष्पीकरण की दर को प्रभावित करने वाले कारक।
  • Cell (कोशिका): पादप और जंतु कोशिका में अंतर, माइटोकॉन्ड्रिया और प्लास्टिड।
  • Motion (गति): चाल, वेग, त्वरण ($a = \frac{v - u}{t}$) एवं न्यूटन के गति नियम।

Class 9th: Mathematics (गणित)

मुख्य सूत्र:

  • Number Systems: अपरिमेय संख्याएं, परिमेयकरण एवं घातांक नियम।
  • Polynomials: बीजीय सर्वसमिकाएं, गुणनखंड एवं शेषफल प्रमेय।
  • Heron's Formula: त्रिभुज का क्षेत्रफल $= \sqrt{s(s-a)(s-b)(s-c)}$

Class 9th: Social Science (सामाजिक विज्ञान)

फ्रांसीसी क्रांति, भारत का आकार और स्थिति, लोकतंत्र क्या और क्यों, तथा पालमपुर गांव की कहानी।

Class 9th: IT 402 (कंप्यूटर)

टच टाइपिंग तकनीक, डिजिटल डॉक्यूमेंटेशन के मूलभूत टूल्स और डेटा एंट्री तकनीक।

Class 10th: Science (विज्ञान)

बोर्ड परीक्षा विशेष बिंदु:

  • रासायनिक अभिक्रियाएं: संयोजन, वियोजन, विस्थापन एवं उपचयन-अपचयन।
  • जैव प्रक्रम: प्रकाश संश्लेषण, मानव श्वसन, परिसंचरण तंत्र एवं उत्सर्जन।
  • प्रकाश: दर्पण सूत्र ($\frac{1}{f} = \frac{1}{v} + \frac{1}{u}$) एवं लेंस सूत्र।
  • विद्युत: ओम का नियम ($V = IR$), प्रतिरोधों का श्रेणी व पार्श्व संयोजन।

Class 10th: Mathematics (गणित)

महत्वपूर्ण सूत्र:

  • द्विघात सूत्र: $x = \frac{-b \pm \sqrt{b^2 - 4ac}}{2a}$
  • त्रिकोणमिति सर्वसमिकाएं: $\sin^2\theta + \cos^2\theta = 1$, $1 + \tan^2\theta = \sec^2\theta$
  • समान्तर श्रेढ़ी (AP): $a_n = a + (n - 1)d$, $S_n = \frac{n}{2}[2a + (n - 1)d]$

Class 10th: Social Science (सामाजिक विज्ञान)

भारत में राष्ट्रवाद (सत्याग्रह और आंदोलन), संसाधन एवं विकास, सत्ता की साझेदारी और मुद्रा एवं साख।

Class 10th: IT 402 (कंप्यूटर)

स्टाइल प्रबंधन, मेल मर्ज, स्प्रेडशीट में डेटा संकलन, गोल सीक, मैक्रोज़ और रिलेशनल डेटाबेस (RDBMS)।

Class 11th: Physics (भौतिकी)

विमीय विश्लेषण, प्रक्षेप्य गति, न्यूटन के गति नियम, कार्य-ऊर्जा प्रमेय एवं गुरुत्वाकर्षण नियम।

Class 11th: Chemistry (रसायन)

मोल अवधारणा, परमाणु संरचना (बोहर मॉडल), रासायनिक आबंधन (संकरण) और थर्मोडायनामिक्स।

Class 11th: Mathematics (गणित)

समुच्चय सिद्धांत, संबंध एवं फलन, सम्मिश्र संख्याएं, द्विपद प्रमेय एवं सीमा और अवकलज।

Class 11th: Biology (जीव विज्ञान)

पंच जगत वर्गीकरण, कोशिका चक्र, समसूत्री व अर्धसूत्री विभाजन और पादप कार्यिकी।

Class 11th: Computer Science (Python)

Python टोकन्स, डेटा टाइप्स (List, Tuple, Dictionary), कंडीशनल स्टेटमेंट्स और लूप्स।

Class 12th: Physics (भौतिकी)

बोर्ड परीक्षा विशेष:

  • स्थिरवैद्युतिकी: कूलॉम नियम, विद्युत क्षेत्र और गाउस प्रमेय।
  • धारा विद्युत: किरचॉफ के नियम, व्हीटस्टोन ब्रिज सिद्धांत।
  • प्रकाशिकी: तरंगाग्र, व्यतिकरण, विवर्तन और ध्रुवण।
  • अर्धचालक: p-n संधि डायोड, रेक्टिफायर एवं लॉजिक गेट्स।

Class 12th: Chemistry (रसायन)

विलयन (राउल्ट का नियम, अणुसंख्य गुणधर्म), इलेक्ट्रोकेमिस्ट्री (नेर्नस्ट समीकरण), और कार्बनिक अभिक्रियाएं।

Class 12th: Mathematics (गणित)

आव्यूह एवं सारणिक ($A^{-1}$ ज्ञात करना), कैलकुलस (अवकलन एवं समाकलन) तथा सदिश व 3-D ज्यामिति।

Class 12th: Biology (जीव विज्ञान)

मानव जनन तंत्र, आनुवंशिकी (मेंडल के नियम, DNA संरचना) और जैव प्रौद्योगिकी के अनुप्रयोग।

Class 12th: Computer Science (Python & SQL)

बोर्ड परीक्षा पाठ्यक्रम:

  • Python File Handling: Text, Binary (pickle) और CSV फाइलें।
  • Data Structures: स्टैक का कार्यान्वयन (Push, Pop ऑपरेशन्स)।
  • Computer Networks: टोपोलॉजी, प्रोटोकॉल (HTTP, FTP, DNS) और नेटवर्क डिवाइस।
  • SQL Queries: GROUP BY, HAVING, Aggregate Functions और Joins।
